# 史料参考文档

本目录收录游戏开发过程中参考的史料长编，供事件卡与人物轨迹设计使用。

## 文档说明

### 崇祯朝史料长编.md

按年编次崇祯朝（1628-1644）大事，据《国榷》《明史》《明季北略》等史料辑录。
每年度列关键事件与人物动态，供事件卡时间线参考。

### 崇祯朝人物志.md

分类辑录崇祯朝重要人物小传，包括：
- 内阁辅臣（温体仁、周延儒、杨嗣昌等）
- 辽东将帅（袁崇焕、祖大寿、孙承宗、洪承畴、卢象升等）
- 东江将帅（毛文龙、孔有德、耿仲明等）
- 流寇首领（李自成、张献忠、高迎祥等）
- 宦官（魏忠贤、高起潜等）
- 其他人物（徐光启、钱谦益等）

每人物列生平要事、《明史》原文引述、游戏定位建议。

### 崇祯朝官员年表.md

按年编次崇祯朝（1628-1644）内阁首辅、大学士、六部尚书、左都御史，以及蓟辽、宣大、陕西三边、剿寇督师总督的任免。
中枢据《明史》卷一一〇《宰辅年表》、卷一一二《七卿年表》，方面据相关列传及吴廷燮《明督抚年表》参校。
附方面沿革表与《考异》十二条，凡史文无月者不系月。

### 崇祯朝奏疏辑要.md

辑录崇祯朝重要大臣奏疏，据《国榷》《明史》《明季北略》等史料。
包括：
- 韩爌请定逆案规模
- 钱龙锡请核东江饷
- 袁崇焕平台召对、请裁东江饷、斩毛文龙疏
- 孙承宗请守通州、守通州疏、被劾疏、临终疏
- 袁崇焕狱中疏
- 祖大寿大凌河被围疏、伪降疏
- 孔有德叛疏、降虏疏
- 杨嗣昌十面之网疏
- 卢象升请战疏、战死疏
- 洪承畴松山败后疏
- 祖大寿锦州降疏

供事件卡文案与人物决策参考。

### 崇祯朝大事详编.md

详录崇祯朝重大事件，据《国榷》《明史》《明季北略》等史料。
包括：
- 己巳之变（崇祯二年十月-十二月）：日次记录
- 袁崇焕案（崇祯二年十二月-三年八月）：下狱、审讯、处死
- 大凌河之战（崇祯四年八月-十月）：被围、粮尽、伪降、逃归、城破
- 登莱之乱（崇祯五年正月-六年十月）：叛乱、陷登州、围莱州、降后金
- 松锦之战（崇祯十四年-十五年）：松山之战、败绩、降清、锦州陷
- 高阳殉难（崇祯十一年二月）：守城、城破、殉难
- 凤阳之变（崇祯八年正月）：破凤阳、焚皇陵
- 李自成破北京（崇祯十七年三月）：破北京、崇祯自缢

供事件卡详细文案参考。

## 史料来源

1. **《国榷》**，谈迁撰。编年体明史，崇祯朝部分尤详。
2. **《明史》**，张廷玉等撰。清官修，列传部分可参。
3. **《明季北略》《明季南略》**，计六奇撰。野史笔记，多轶闻。
4. **《崇祯长编》**，佚名撰。崇祯朝编年史料。
5. **《明史纪事本末》**，谷应泰撰。

## 使用说明

- 本文档为游戏开发参考，史料取舍以叙事需要为准，非严格考据。
- 新增事件卡时，应先查史料长编确认时间线。
- 新增人物时，应先查人物志确认生平与游戏定位。
- 新增事件文案时，可参考奏疏辑要与大事详编。
- 如有史料冲突，以《国榷》为准（编年体，崇祯朝最详）。

# 史料参考文档

本目录收录游戏开发过程中参考的史料长编，供事件卡与人物轨迹设计使用。

## 文档说明

### 崇祯朝史料长编.md

按年编次崇祯朝（1628-1644）大事，据《国榷》《明史》《明季北略》等史料辑录。
每年度列关键事件与人物动态，供事件卡时间线参考。

### 崇祯朝人物志.md

分类辑录崇祯朝重要人物小传，包括：
- 内阁辅臣（温体仁、周延儒、杨嗣昌等）
- 辽东将帅（袁崇焕、祖大寿、孙承宗、洪承畴、卢象升等）
- 东江将帅（毛文龙、孔有德、耿仲明等）
- 流寇首领（李自成、张献忠、高迎祥等）
- 宦官（魏忠贤、高起潜等）
- 其他人物（徐光启、钱谦益等）

每人物列生平要事、《明史》原文引述、游戏定位建议。

## 史料来源

1. **《国榷》**，谈迁撰。编年体明史，崇祯朝部分尤详。
2. **《明史》**，张廷玉等撰。清官修，列传部分可参。
3. **《明季北略》《明季南略》**，计六奇撰。野史笔记，多轶闻。
4. **《崇祯长编》**，佚名撰。崇祯朝编年史料。
5. **《明史纪事本末》**，谷应泰撰。

## 使用说明

- 本文档为游戏开发参考，史料取舍以叙事需要为准，非严格考据。
- 新增事件卡时，应先查史料长编确认时间线。
- 新增人物时，应先查人物志确认生平与游戏定位。
- 如有史料冲突，以《国榷》为准（编年体，崇祯朝最详）。

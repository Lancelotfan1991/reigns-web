# 崇祯朝官员年表（1628—1644）

> 起崇祯元年戊辰（1628），讫崇祯十七年甲申三月（1644）。逐年纪内阁首辅、大学士，吏、户、礼、兵、刑、工六部尚书，都察院左都御史，以及蓟辽、宣大、陕西三边、剿寇督师总督之任免。月份为农历，只系月不系日；诸书异说，别为《考异》。

## 一、体例

1. **纪年**：崇祯年号＋干支＋公历年份。公历仅标年份，不逐条换算月日；崇祯十七年止于三月十九日京师陷落。
2. **中枢**：内阁首辅、大学士；六部尚书；左都御史。南京留都、侍郎、巡抚、寺监、科道不列。
3. **方面**：蓟辽（含辽东督师）、宣大、陕西三边、剿寇总理及督师。保定、漕运、凤阳、郧阳、南赣等总督，除与剿寇全局相关者外从略。
4. **符号**：“→”表示先后递嬗；“（兼）”表示兼领；“署”表示署理；“待考”表示史文无月或诸说不合，不强系月分。
5. **取舍**：只列实际任事者。官至某部尚书而未任事、任命未行、或南明追授者，原则上不列；必要者加注说明。
6. **材料**：中枢任免以《明史》卷一一〇《宰辅年表二》、卷一一二《七卿年表二》为主；方面任免以《明史》卷七三《职官志二》及卷二百五十一、二百五十七、二百六十、二百六十二诸传为主，月分间取吴廷燮《明督抚年表》所辑，并以本传校之。异说见文末《考异》。

## 五、考异

**一、崇祯元年六月至十二月首辅。**

《明史》卷二五一《李标传》：“庄烈帝嗣位，即家拜礼部尚书兼东阁大学士。崇祯元年三月入朝。未几，李国𣚴、来宗道、杨景辰相继去，标遂为首辅。……是冬，韩爌还朝，标让为首辅。”据此，元年六月至十二月首辅为李标。通行《明朝首辅列表》以周道登当此任，盖据《宰辅年表》“道登六月任”之文；然同表李标“二月任”、刘鸿训“二月任”、钱龙锡“六月任”，诸“任”多指到任视事，非谓首辅。今从《李标传》，周道登仍列大学士。

**二、崇祯十一年干支。**

通行七卿年表有以崇祯十一年为“丁丑”者，实为戊寅；丁丑乃崇祯十年。本表正之。

**三、刘遵义与刘遵宪。**

《明史》卷一一二崇祯三年工部尚书作“刘遵义”，七年以后作“刘遵宪”，且七年下有“复任”二字。疑为一人而异写，或为两人，史文简略，待考。

**四、傅宗龙蓟辽总督始年。**

《明史》卷二六二《傅宗龙传》云崇祯三年起故官，巡抚顺天，未几拜兵部右侍郎，总督蓟、辽、保定军务；未系总督始年。吴廷燮《明督抚年表》系于五年九月，与曹文衡五年九月罢相合。本表从五年九月，存异。

**五、丁魁楚下吏月分。**

《明史》卷二六〇《丁魁楚传》云九年七月畿辅被兵，坐下吏；通行督抚表云十月下刑部。本表作“九年下吏”，不系月。

**六、陈新甲宣大任期。**

《明史》卷二五七《陈新甲传》云十一年六月代卢象升为宣大总督，十三年正月召代傅宗龙为兵部尚书。通行宣大表系于十二年，与本传不合，本表从本传。

**七、陈新甲下狱月分。**

《明史》卷二五七《陈新甲传》云崇祯十五年七月因马嘉植劾奏下狱，从狱中上书乞宥，不许，“遂弃新甲于市”，未系弃市月分；卷一一二《七卿年表》则云“新甲八月下狱，弃市”。本表从本传作七月下狱，弃市不系月；八月下狱之说并存备考。

**八、熊文灿罢逮。**

《明史》卷二六〇《熊文灿传》云十二年五月张献忠反于谷城，帝削文灿官，戴罪视事；七月命杨嗣昌来代，寻逮下狱；十三年十月弃市。本表分系削官、逮狱、弃市，不并为一事。

**九、郑崇俭之死。**

《明史》卷二六〇《郑崇俭传》云十四年春献忠陷襄阳、嗣昌死，帝逮崇俭下狱，以五月弃市。通行表或系于十三年，误。

**十、傅宗龙与丁启睿的三边重叠。**

《明史》卷二六〇《丁启睿传》云十四年嗣昌死，启睿加兵部尚书，改称督师，仍兼总督陕西三边军务；而同卷《傅宗龙传》云十四年春傅宗龙代丁启睿总督陕西三边。盖启睿改督师后，三边事务实际由宗龙任之，“仍兼”存其名而已。本表以实际任事为准。

**十一、崇祯十七年三月以后之任命。**

《明史》卷一一二崇祯十七年三月下列王铎“召，未赴”、陈必谦“任，甲申难后脱归”等。王铎、陈必谦之命，史文简略，或出南明，或出崇祯末命，难以遽断。本表陈必谦加“甲申难后脱归”注，王铎加“未赴”注；三月十九日以后南明授官，一概不列。

**十二、崇祯十七年工部尚书陈必谦。**

《明史》卷一一二云“陈必谦三月任，甲申难后脱归”。是必谦确受尚书之命，且身历甲申之难，非纯南明追授。本表列之，而系于三月之末，以存疑。

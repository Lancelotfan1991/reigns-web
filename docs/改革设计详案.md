# 崇祯朝改革设计详案

> 这份文档把“改革”从一句口号拆成可制作的卡组、数值和前置条件。  
> 目标不是一次把所有改革做完，而是让每一项都能独立成一组“步骤卡 + 挑战卡 + 结算”。

## 一、统一规则

### 1. 三资源

| 代号 | 资源 | 作用 |
|---|---|---|
| **P** | 政治威望 | 解锁改革、影响执行效率；0 时改革全部锁死 |
| **S** | 综合国力 | 支付改革成本、战争与灾难；0 时亡国 |
| **M** | 民心 | 影响国力消耗、恢复速度和民变风险 |

旧资源继续作为卡牌效果使用：

- **C** 君威
- **L** 法度
- **A** 军心
- **G** 国库（万两）

### 2. 改革生命周期

每项改革统一做成六个节点：

1. **提议**：是否立项；
2. **试点**：小范围验证；
3. **推进**：全面铺开；
4. **挑战一**：既得利益反扑；
5. **挑战二**：执行偏差或外部危机；
6. **结算**：成功、部分成功、失败。

每张步骤卡包含：

```ts
{
  id, title, body,
  costGold, costManpower, duration,
  successRate, boostConditions, requiredRoles,
  effects: { P?, S?, M?, C?, L?, A?, G? }
}
```

每张挑战卡包含两个选项，各自有明确代价和后果。

### 3. 执行判定

沿用现有 2d6 判定：

```text
2d6 + 威望修正 + 承办官修正 + 国力/民心修正 >= 6 + 难度
```

建议：

- 威望每高于 50 十点，+1；
- 承办官按现有五维取修正；
- 国力低于 30，改革判定 -1；
- 民心低于 30，涉及加税、征役的改革 -1。

### 4. 数值尺度

- 小型效果：±2—4；
- 中型效果：±5—8；
- 大型效果：±10—15；
- 一次性国库：以“万两”计；
- 持续性收入：写“每年”。

## 二、初阶改革：威望 ≥ 20

### 1. 裁撤驿站

- **ID**：`postal-cuts`
- **类别**：财政
- **历史依据**：崇祯二年裁驿，刘懋主持；陕西驿卒失业，是李自成起事的重要背景。
- **目标**：裁并冗站，节省驿银，同时避免驿卒流入流寇。

**三步：**

1. **清点驿站**：核马匹、夫役、支应账目；花费 5 万两，0.5 年，成功率 80%。
2. **裁并三成**：裁撤冗站，保留军报干线；花费 10 万两，1 年，成功率 65%。
3. **安置驿卒**：给转业粮、垦荒地和军籍；花费 15 万两，1 年，成功率 55%。

**挑战：**

- **陕西驿卒聚众**：  
  A. 派兵镇压：`A+3, M-10, P-2`，但短期压住；  
  B. 发安置银：`G-20万, M+5, P+2`，财政更紧。
- **军报迟滞**：  
  A. 恢复关键驿站：`G-8万, A+3`；  
  B. 裁减过猛，边报延误：`A-6, P-3`。

**结算：**

- 成功：`G+30万/年, S+3, P+3`；
- 部分成功：`G+15万/年, M-3`；
- 失败：`G+5万, M-10, P-5`，并种下“驿卒从贼”旗标。

### 2. 历局修历

- **ID**：`calendar-bureau`
- **类别**：工业
- **历史依据**：崇祯二年开局修历，徐光启、汤若望、龙华民参与。
- **目标**：恢复朝廷的颁朔、天文和测量能力。

**三步：**

1. **设局译书**：5 万两，0.5 年，成功率 80%；
2. **制仪观象**：8 万两，1 年，成功率 65%；
3. **颁行新历**：5 万两，0.5 年，成功率 55%。

**挑战：**

- **旧历官抵制**：  
  A. 保留旧历官、新旧互校：`C+3, P+2, G-3万`；  
  B. 强行废旧历：`P-3, L-5, C-3`。
- **西法争议**：  
  A. 只取历算、不涉教义：`P+3, L+2`；  
  B. 全面采用西法：`P-2, M-3, S+5`，长期技术收益更大。

**结算：**

- 成功：`P+4, C+3, S+3`，解锁“测量/火器/农时”加成；
- 失败：`P-3, G-10万`，历局保留但威信受损。

## 三、中阶改革：威望 ≥ 40—60

### 7. 开海禁

- **ID**：`open-maritime`
- **类别**：财政
- **威望**：40
- **历史依据**：隆庆开关、月港、郑芝龙海上势力。
- **目标**：设海关、发船引、征海税，不是“海权国家”。

**三步：**

1. **设海关**：10 万两，0.5 年，成功率 80%；
2. **发船引**：5 万两，0.5 年，成功率 70%；
3. **建水师护商**：15 万两，1 年，成功率 60%。

**挑战：**

- **荷兰/走私集团**：  
  A. 联合郑芝龙迎战：`A+3, G-10万, P+2`；  
  B. 给贸易特权换和平：`G-20万, P-3, M-2`。
- **保守派反对**：  
  A. 公开辩论、皇帝担责：`P+4, C-2`；  
  B. 妥协只开月港：`G+50万/年, P-2`。

**结算：**

- 成功：`G+100万/年, S+4, P+4`；
- 失败：`G-20万, P-5, M-3`。

> 注意：开海只是中阶。真正的高阶是“海关税成为财政主轴 + 海军 + 国家银行”。

## 五、改制：威望 100

> 到 100 威望，不再是“通过一项改革”，而是“决定明朝以后谁说了算”。  
> 建议只开放一次“改制会议”，只能选一条国体路线。

### 改制前置：崇祯约法

- **ID**：`chongzhen-covenant`
- **威望**：100
- **性质**：不是普通改革，而是“改制会议”的入场券。
- **内容**：
  - 皇帝公开限制自己随意杀大臣、绕开预算加派、派太监监军的权力；
  - 设立预算会议，士绅、商人、军队代表参与；
  - 重大战略由君臣共同署名，失败共同担责。
- **效果**：
  - `P+8, C-6, L+8, G+50万/年`；
  - 解锁“虚君内阁”“均田清税”“新军国”等改制路线。
- **风险**：
  - 保守派骂“自弃乾纲”；
  - 如果皇帝之后反悔，政治威望会一次性崩塌。

### 21. 虚君内阁

- **前置**：完成“崇祯约法”、预算会议、至少两位核心大臣支持。
- **效果**：
  - 内阁对士绅议会负责；
  - 皇帝保留否决权和外交权；
  - `P+10, C-10, L+8, G+100万/年`；
  - 长期：政策连续、税收稳定、皇帝不再被日常政务拖死。
- **风险**：皇权被架空，保守派政变，皇帝可能成为傀儡。
- **结局倾向**：君主立宪 / 长期稳定。

### 22. 均田清税

- **前置**：完成“清查隐田”、鱼鳞图册、至少一省试点。
- **效果**：
  - 全国按田亩、财产征赋；
  - `G+500万/年, S+10, P+5, M-10`；
  - 士绅优免大幅削减。
- **风险**：士绅集体反抗，地方抗税，可能内战。
- **结局倾向**：财政国家 / 士绅反扑。

### 23. 新军国

- **前置**：完成“实兵实饷”“火器精进”，卢象升/孙传庭支持。
- **效果**：
  - 废卫所，建常备军；
  - `A+15, S+8, G-200万/年`；
  - 解锁新军编制、参谋制度、军官学校。
- **风险**：旧军头叛乱，军费失控，新军军阀化。
- **结局倾向**：军事强权 / 军阀化。

### 24. 国家银行

- **前置**：完成“推行纸币”“交叉验账”“开海禁”。
- **效果**：
  - 统一银钱、纸币、汇兑；
  - `G+200万/年, S+8, P+5`；
  - 解锁战争公债、低息借款。
- **风险**：超发、挤兑、伪钞、商人垄断。
- **结局倾向**：财政革命 / 金融崩溃。

### 25. 海权国家

- **前置**：完成“开海禁”的设海关、发船引、建水师三个阶段。
- **效果**：
  - 海关税成为财政主轴；
  - `G+300万/年, S+8, P+5`；
  - 解锁远洋贸易、海外据点、海军部。
- **风险**：内陆士绅不满、海防失衡、沿海集团坐大。
- **结局倾向**：海贸帝国 / 南北分裂。

### 26. 新学取士

- **前置**：完成“实学科考”“废除八股”。
- **效果**：
  - 中央大学堂 + 地方实学；
  - `P+8, S+8, G+50万/年`；
  - 解锁技术官、军需官、外交官。
- **风险**：士林长期敌视、地方教育失控。
- **结局倾向**：技术官僚国家 / 文化断裂。

## 八、制作时不要忘的三件事

1. **每项改革都要有失败后果**，不能只有“成功收益”。
2. **每项改革都要改变至少一项旧资源**，不能只加新三资源。
3. **高阶改革必须互相牵制**，不能让玩家无脑全点。

一句话：

> **改革不是一张“政策购买清单”，而是一串会反噬的政治交易。**
